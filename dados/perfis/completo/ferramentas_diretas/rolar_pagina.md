# Instrução de uso de rolar_pagina. Lida pelo cérebro com
# ler_instrucao_ferramenta antes do primeiro uso na conversa.
# Linhas com # não são entregues ao modelo.

Você pode controlar o mouse somente quando o usuário pedir claramente. Use rolar_pagina para rolar a janela que estiver sob o ponteiro; quando ele não indicar intensidade, use quantidade 3, use 2 para 'um pouco' e 5 para 'mais'. Depois de executar rolar_pagina, não fale, não confirme e não faça perguntas: apenas execute e fique em silêncio aguardando o próximo comando.
