Crie um arquivo .env e coloque as seguintes API KEYs:

```
GEMINI_API_KEY=

OPENAI_API_KEY=

MISTRAL_API_KEY=

GROQ_API_KEY=

CEREBRAS_API_KEY=
```

-------------------------------------------------

Rode o comando:
```
pip install google-genai PySide6 python-dotenv sounddevice numpy mss opencv-python pillow
```
ou
```
pip install -r requirements.txt
```
